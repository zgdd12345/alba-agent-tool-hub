# agenthub v0.3.3 — Backlog Cleanup

> Focused cleanup before starting Plan 4 (Pillar 5). Tackles the 3 highest-impact backlog items from v0.2/v0.3 simplify passes. Skips structural refactors (PluginRef union, PlanItem split) per YAGNI.

**Goal:** Three targeted fixes that each give measurable improvement:
1. **OpenCode bun-install batching** — currently runs `bun install` N times for N plugins; should run once.
2. **`filecmp.cmp` for tree diff** — currently reads file bytes into Python heap; should stream.
3. **Atomic temp-rename in fetcher fallback** — currently has a window where cache dir is gone but no error is persisted.

**Tech stack:** No new deps; uses stdlib `filecmp` and existing patterns.

**Scope of v0.3.3:** 5 implementation tasks + tag.

**Out of scope (v0.4+):**
- `PluginRef` tagged union refactor (works as-is)
- `PluginPlanItem` separate from content `PlanItem` (works as-is)
- batch-by-URL source fetch in `--all`
- `_installer_cmd` PATH cache
- Test subprocess argument-shape coverage

class OpenCodeTarget:
    name = "opencode"

    def __init__(self) -> None:
        self._dirty = False

    def detect(self) -> bool: ...
    def global_root(self) -> Path: ...
    def project_root(self, project_path: Path) -> Path: ...
    def content_subdir(self, kind: str) -> str: ...

    def install_plugin(self, ref: PluginRef) -> None:
        pkg = _package_json(self.global_root())
        pkg.parent.mkdir(parents=True, exist_ok=True)
        deps = _read_dependencies(pkg)
        version = ref.version if ref.version else "latest"
        deps[ref.npm_package] = version
        _write_package_json(pkg, deps)
        self._dirty = True

    def uninstall_plugin(self, name: str) -> None:
        pkg = _package_json(self.global_root())
        if not pkg.exists():
            return
        deps = _read_dependencies(pkg)
        if name not in deps:
            return
        deps.pop(name)
        _write_package_json(pkg, deps)
        self._dirty = True

    def apply_pending_changes(self) -> None:
        if not self._dirty:
            return
        rc, _, err = run_subprocess(_installer_cmd(), cwd=self.global_root())
        if rc != 0:
            raise RuntimeError(f"npm/bun install failed: {err.strip()}")
        self._dirty = False

    def list_installed_plugins(self) -> set[str]: ...

## Task T5 — Atomic temp-rename in `fetch_to_cache` fallback

**Files:**
- Modify: `src/agenthub/core/git_source.py`

- [ ] **Step 1: Refactor the fresh-clone fallback path**

Current code (`git_source.py` `fetch_to_cache`, fallback after first `-b` clone fails):
```python
if dest.exists():
    shutil.rmtree(dest)
rc2, _, err2 = run_git(["clone", "--depth=1", "--no-tags", url, str(dest)])
```

New (atomic temp-dir → rename on success):
```python
import tempfile

if dest.exists():
    # Stash the partial clone; we'll clean it up after a successful new one
    shutil.rmtree(dest)
parent = dest.parent
parent.mkdir(parents=True, exist_ok=True)
with tempfile.TemporaryDirectory(dir=str(parent), prefix=".clone-tmp-") as tmpdir:
    tmp_dest = Path(tmpdir) / "repo"
    rc2, _, err2 = run_git(["clone", "--depth=1", "--no-tags", url, str(tmp_dest)])
    if rc2 != 0:
        raise GitFetchError(f"git clone failed: {err.strip() or err2.strip()}")
    rc3, _, err3 = run_git(["fetch", "--depth=1", "origin", ref], cwd=tmp_dest)
    if rc3 != 0:
        raise GitFetchError(f"git fetch failed: {err3.strip()}")
    rc4, _, err4 = run_git(["checkout", "FETCH_HEAD"], cwd=tmp_dest)
    if rc4 != 0:
        raise GitFetchError(f"git checkout failed: {err4.strip()}")
    # All ops succeeded; atomic rename into final location
    shutil.move(str(tmp_dest), str(dest))
```

Note: `TemporaryDirectory` cleans up on exception (best-effort), so an interrupted clone leaves no orphan dirs.
