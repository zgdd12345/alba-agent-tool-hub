# agenthub v0.3.2 — Codex Plugin Completion

> Small implementation plan that closes the Codex plugin stub left in v0.3.0. Based on real-machine probing of `codex plugin` CLI (2026-05-18).

**Goal:** Replace `CodexTarget.install_plugin` / `uninstall_plugin` stubs (`NotImplementedError`) with real implementations using the verified `codex plugin marketplace` CLI + `~/.codex/config.toml` editing.

**Spec §1.6 update:** Codex plugin install CLI is **marketplace-centric** (not plugin-centric like Claude). The CLI surface is:
```
codex plugin marketplace add <SOURCE>     # SOURCE = owner/repo[@ref] | git URL | local path
codex plugin marketplace upgrade [NAME]
codex plugin marketplace remove <NAME>
```
There is **no** `codex plugin install <plugin>`. Plugin enablement is controlled by editing `~/.codex/config.toml` and adding `[plugins."<plugin>@<marketplace>"] enabled = true` per plugin.

**Marketplace name discovery:** the marketplace name (e.g. `openai-curated`) is declared in the upstream marketplace's manifest file inside `.codex-plugin/`. Reliable programmatic auto-derivation from URL is **not** possible — agenthub must accept it as user input.

---

## Schema change

`PluginRef` gains an **optional** field for Codex-specific use:

```python
@dataclass(frozen=True, slots=True)
class PluginRef:
    type: PluginType
    marketplace: str = ""           # Claude: marketplace URL; Codex: marketplace SOURCE (owner/repo or URL)
    plugin: str = ""                # plugin name within the marketplace
    npm_package: str = ""           # OpenCode only
    version: str = "latest"
    description: str = ""
    tags: tuple[str, ...] = field(default_factory=tuple)
    marketplace_name: str = ""      # NEW: Codex-only — name as registered in config.toml (e.g. "openai-curated")
```

`_validate(ref)` updates:
- For Codex (marketplace type targeted at codex tool): require `marketplace_name` non-empty. Else raise `PluginError("Codex plugin requires --marketplace-name (the registered name in config.toml)")`.

**However**: `PluginRef` is target-agnostic in v0.3.0; validation can't tell if it's a Codex ref. Two options:
- A. Require `marketplace_name` for ALL marketplace types (Claude tolerates it as a no-op)
- B. Defer validation to install-time (CodexTarget.install_plugin raises if `marketplace_name` empty)

**Choose B** — keeps PluginRef schema target-agnostic, surfaces error at the right time.

---

## CLI change

`agenthub plugin add -t codex` gains `--marketplace-name <name>`:

```
agenthub plugin add -t codex \
    --marketplace openai/codex-plugins \
    --plugin figma \
    --marketplace-name openai-curated \
    --version 2.0.7
```

For Claude/OpenCode, `--marketplace-name` is ignored (no-op pass-through into PluginRef).

```python
# src/agenthub/targets/codex.py
from __future__ import annotations

from pathlib import Path

import tomlkit

from agenthub.core.git_subprocess import run_subprocess
from agenthub.core.plugin import PluginRef


class CodexTarget:
    name = "codex"

    def detect(self) -> bool:
        return self.global_root().exists()

    def global_root(self) -> Path:
        return Path.home() / ".codex"

    def project_root(self, project_path: Path) -> Path:
        return project_path / ".codex"

    def content_subdir(self, kind: str) -> str:
        return {"skill": "skills", "command": "prompts", "agent": "agents"}[kind]

    def install_plugin(self, ref: PluginRef) -> None:
        if not ref.marketplace_name:
            raise RuntimeError(
                "Codex plugin install requires marketplace_name "
                "(the name registered in config.toml, e.g. 'openai-curated'). "
                "Pass --marketplace-name when running `agenthub plugin add`."
            )
        # 1) Idempotent marketplace add: try; ignore "already configured" errors
        rc, _, err = run_subprocess(
            ["codex", "plugin", "marketplace", "add", ref.marketplace]
        )
        if rc != 0 and "already" not in err.lower():
            raise RuntimeError(f"codex plugin marketplace add failed: {err.strip()}")
        # 2) Edit config.toml to enable the plugin
        cfg_path = self.global_root() / "config.toml"
        self._enable_plugin_in_config(cfg_path, ref.plugin, ref.marketplace_name)

    def uninstall_plugin(self, name: str) -> None:
        """Disable plugin in config.toml. Requires `<plugin>@<marketplace>` form."""
        cfg_path = self.global_root() / "config.toml"
        self._disable_plugin_in_config(cfg_path, name)

    def list_installed_plugins(self) -> set[str]:
        cache = self.global_root() / "plugins" / "cache"
        if not cache.exists():
            return set()
        names: set[str] = set()
        for marketplace_dir in cache.iterdir():
            if not marketplace_dir.is_dir():
                continue
            for plugin_dir in marketplace_dir.iterdir():
                if plugin_dir.is_dir():
                    names.add(plugin_dir.name)
        return names

    @staticmethod
    def _enable_plugin_in_config(cfg_path: Path, plugin: str, marketplace: str) -> None:
        if cfg_path.exists():
            doc = tomlkit.parse(cfg_path.read_text())
        else:
            doc = tomlkit.document()
            cfg_path.parent.mkdir(parents=True, exist_ok=True)
        key = f'plugins."{plugin}@{marketplace}"'
        # tomlkit handles dotted/quoted keys via nested tables
        plugins_tbl = doc.get("plugins")
        if plugins_tbl is None:
            plugins_tbl = tomlkit.table()
            doc["plugins"] = plugins_tbl
        plug_key = f"{plugin}@{marketplace}"
        if plug_key in plugins_tbl:
            entry = plugins_tbl[plug_key]
        else:
            entry = tomlkit.table()
            plugins_tbl[plug_key] = entry
        entry["enabled"] = True
        cfg_path.write_text(tomlkit.dumps(doc))

    @staticmethod
    def _disable_plugin_in_config(cfg_path: Path, plugin_or_full: str) -> None:
        """Remove the [plugins."<plugin>@<marketplace>"] entry. Accept either
        full `plugin@marketplace` key or bare plugin name (will remove all matches)."""
        if not cfg_path.exists():
            return
        doc = tomlkit.parse(cfg_path.read_text())
        plugins_tbl = doc.get("plugins")
        if plugins_tbl is None:
            return
        # Find matching keys
        to_remove = []
        for key in list(plugins_tbl.keys()):
            if key == plugin_or_full or key.startswith(f"{plugin_or_full}@"):
                to_remove.append(key)
        for key in to_remove:
            del plugins_tbl[key]
        if not plugins_tbl:
            del doc["plugins"]
        cfg_path.write_text(tomlkit.dumps(doc))
```
